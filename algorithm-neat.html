NEAT

Instead of tuning 11 fixed weights, evolve the network's shape itself — starting tiny and growing new connections and nodes only when they earn their keep.

Same 11 inputs, a network instead of a dot product

GA and CMA-ES both score a board as one fixed weighted sum. NEAT scores it by running the same 11 features through a small evolved neural network — so it can learn combinations a straight weighted sum never could.
